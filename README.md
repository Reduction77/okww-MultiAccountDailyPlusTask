# okww 自定义任务集

适用于 [ok-wuthering-waves](https://github.com/ok-oldking/ok-wuthering-waves)（ok-ww）的自定义任务：

1. **多账号每日+**：在官方「多账号每日任务」基础上，支持每个账号自选刷第几个无音区，并按输入顺序执行
2. **多账号周常乐园**：自动切换所有账号刷满周常乐园

## 环境要求

- ok-ww 版本不早于 2026-05（约 v3.5+，即官方「多账号每日任务」重构之后的版本，最新版直接用即可）
- 无需修改任何官方源码，上游更新（覆盖安装 / 在线更新）后无需重装本任务

## 安装

把需要的 `.py` 文件放进 ok-ww 安装目录下的 `ok_tasks/` 文件夹，重启 ok-ww 即可在任务列表中看到。

## 稳定性说明（v1.4）

两个任务共享同一套增强机制：

- **游戏抢前台时自动让出焦点（每一次点击/按键前都会检查）**：鸣潮抢到前台后走 RawInput，会无视 PostMessage 后台点击/按键（或让点击落到物理鼠标所在位置，选号时表现为一直点中同一个账号、陷入死循环），而游戏在**每一次**登录切换时都会自己抢前台。因此本任务把检查下沉到了输入层——脚本发出的每一次点击和按键之前都会先检测前台状态，游戏一旦抢到前台就立即把焦点让给其他窗口（游戏画面原地不动，只是失去激活状态），覆盖包括官方选号流程内部在内的所有步骤，无需再手动切窗口。
- **登录点击防抖，与官方同节奏**：ok-script 的执行器是单线程的——一次性任务运行期间，「自动登录」这类触发任务根本不会被调度，登录点击全部来自任务自身 ensure_main 的逐帧轮询，读条期间「进入游戏」被每秒连点、动画反复重启，画面就一直闪。本任务给登录点击加了 5 秒防抖（与官方自动登录的触发间隔一致），防抖窗口内只做状态检测不点击，等效于让官方的节奏来点。
- **返回登录界面自愈重试**：上游官方流程是单次盲操作（esc 只发一次不校验、确认弹窗写死等 1 秒、等不到登录界面就直接报错），任何一次输入丢失都会卡死或退出。本任务重写为：先回到主界面 → 发 esc 并校验终端菜单真的打开（没开就重发，最多 3 次）→ 点「返回登录」→ 真实等待确认弹窗（最多 5 秒）→ 等待登录界面出现；整套流程失败自动重来，最多 3 次。
- **切号失败自动恢复**：选号/登录流程失败会截图并恢复到登录界面重试，连续失败 3 次才中止任务。

另外两点属于游戏自身行为，脚本无法屏蔽，了解即可：

- 游戏在登录/读条切换时会自己把窗口抢到前台，与 ok-ww 无关；
- 游戏窗口被完全遮挡或最小化时读条会变慢甚至暂停，运行时尽量不要最小化游戏窗口。

## 任务一：👥 Multi Account Daily+ 多账号每日+

文件：`MultiAccountDailyPlusTask.py`

### 使用方法

1. 在「每日任务」里确认 **Which to Farm 设为 Tacet Suppression（无音区）**——编号覆盖只有在这种情况下才生效；设成凝素领域/模拟领域时覆盖会被忽略。
2. 在本任务的配置项 **「Per-Account Tacet 每账号无音区」** 里，每行添加一条（可一次粘贴多行）：

   ```
   打码账号=无音区编号
   ```

   例如：

   ```
   133****8952=3
   177****6962=2
   135****1752=2
   ```

3. 账号名以登录界面显示的打码账号为准（含 4 个星号）；`0/o`、大小写、`.con/.com` 差异会自动容错。

### 执行顺序

- **配置了自选无音区的账号，严格按照配置里的输入顺序依次执行**（先切到登录界面，按顺序定点选号登录）；
- 未配置的账号随后按登录界面下拉列表的顺序执行，仍使用「每日任务」里的全局设置；
- 整个列表留空时行为与官方多账号任务完全一致（先跑当前账号，再按列表顺序跑其余的）；
- 某个账号在登录列表里找不到时（打码名填错或账号已移除），会输出警告并跳过，不影响其他账号。

无音区编号从 1 开始，对应 F2 指南书里的顺序，上限自动跟随 ok-ww 的 TacetTask（当前共 19 个）。

### 实现说明

- 只做内存级覆盖（`dict.__setitem__`），不会改动「每日任务」的持久化配置
- 编号上限动态读取 `TacetTask.total_number`，游戏新增无音区后无需改脚本
- 若 ok-ww 更新后每日任务的配置键改名，脚本会输出警告并回退到全局设置，不会静默刷错本
- 定点选号与官方选号逻辑的差异：只点击目标账号，找不到时不点任何账号，不会误选
- 所有账号跑完后正常结束（官方多账号任务此处会以异常收尾，本任务做了捕获处理）

## 任务二：🎡 Multi Account Garden 多账号周常乐园

文件：`MultiAccountGardenTask.py`

### 使用方法

无需任何配置。从当前已登录的账号开始，依次切换登录界面下拉列表里的所有账号，逐个运行官方「自动周常乐园」。

### 实现说明

- **不需要识别账号**：官方 `GardenTask` 自带完成检测（OCR 是否已达 6000 积分上限），刷过的账号会自动跳过，所以直接让每个账号都跑一遍即可
- 账号切换机制继承官方 `MultiAccountDailyTask`，并叠加了 v1.1 的自愈重试增强（见上方「稳定性说明」）
- 单个账号失败时截图并恢复主界面，继续下一个账号，不中断整体流程
- 所有账号完成后正常结束（官方多账号任务此处会以异常收尾，本任务做了捕获处理）
